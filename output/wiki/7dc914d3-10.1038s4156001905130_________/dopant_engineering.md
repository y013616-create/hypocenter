# 도펀트 설계 (Dopant Engineering)

## Definition
층상 산화물 양극재의 전이금속 자리(또는 리튬 자리)에 소량의 이종 원소를 도입하여 이온 전도도, 구조적·열적 안정성, 속도 성능, 사이클 수명 등의 전기화학적 특성을 조율하는 재료 설계 전략이다. 일반적으로 ppm ~ 수% 수준의 극소량이 사용된다.

## Context in Paper
논문은 Co, Mn, Al의 역할과 한계를 분석한 후(그림 2k), Mg, Zr, Ti, Mo, Nb, W, B, Ta, Cr, Ga, Fe, Na 등 비표준 도펀트를 논의한다. LNO 기반 차세대 초고니켈 조성에서 도펀트 선택 이론이 부재하며 대부분 시행착오에 의존함을 지적하고, 전자 구조 기반 고처리량 스크리닝의 필요성을 강조한다.

## Key Properties / Characteristics

### 주요 도펀트별 역할 비교 (그림 2k 기반)
| 도펀트 | 역할 | 장점 | 단점 |
|--------|------|------|------|
| **Co** | Li⁺/Ni²⁺ 혼합 억제, 속도 성능 향상 | 성능 균형 우수 | 높은 가격, 공급 위험 |
| **Mn** | 구조·열적 안정화, 상전이 억제 (≥20% 필요) | 저비용, 합성 용이 | 더 많은 Li⁺/Ni²⁺ 혼합, 속도 저하 |
| **Al** | 층상 구조 안정화, 잔류 Li 화합물 억제 (5% 충분) | 소량으로 효과 | 구조 강성(균열), 좁은 용해도, 복잡한 합성 |
| **Mg** | 특성 튜닝(수명, 전도도) | 상용 사용 확립 | 대량 사용 시 구조 결함 |
| **Zr, Ti** | 격자 안정화, 금속-산소 결합 강화 | 암염 형성 억제 가능 | 대량 시 불순물·성능 저하 |
| **Nb, W, Ta** | 금속-산소 결합 강화, 구조 안정화 | 고전압 안정성 기대 | 연구 초기 단계 |

### 이온 반경 기반 도펀트 선택 원칙
$$r < r_{Ni^{3+}} (0.56\,\text{Å}) \Rightarrow \text{클러스터링 (예: Al}^{3+}\text{, }0.535\,\text{Å)}$$
$$r > r_{Ni^{3+}} \Rightarrow \text{암염 구조 촉진 또는 Li 슬래브 치환}$$
- Ni²⁺ (0.69 Å), Mg²⁺ (0.72 Å): Li 슬래브 치환 가능
- Ti⁴⁺ (0.605 Å), Zr⁴⁺ (0.72 Å), Nb⁵⁺ (0.64 Å), W⁶⁺ (0.60 Å): 암염 구조 형성 경향

### 최적 도핑량의 특성
- 일반적으로 매우 적은 양 (때로 ppm 수준)
- 대량 도입 시: 구조 결함(양이온 혼합), 격자 왜곡, 불순물 상 → 전기화학적 특성 급격 저하
- 산업 공침법에서 도펀트 균일 분산이 어려움 → 성능 불일치

## Examples
- NMA (Li[NiMnAl]O₂): Co 없이 Mn·Al으로 안정화한 차세대 후보
- NTMA (Li[NiTiMgAl]O₂): Ti·Mg·Al 복합 도핑
- eLNO (Johnson Matthey): 비표준 도핑 LNO 기반 차세대 양극재, 상용화 이정표 달성
- Nb, W, Mo 도핑 LNO: 문헌 보고는 상충된 결과가 많아 이론적 가이드라인 수립 필요
